基本命令

# 设置开机启动docker
systemctl enable docker
# 重启docker
systemctl restart docker
# 镜像:
docker images
docker search xxx
docker pull xxx
docker rmi xxx
# 容器:
docker run -it --name XXX (-v ...:...) xxx:5.0 /bin/bash
docker run -id --name XXX (-v ...:...) xxx:5.0 /bin/bash
docker exec -it XXX /bin/bash
exit
docker start XXX
docker ps # 当前容器
docker ps -a # 所有容器
docker stop XXX
docker rm XXX
# 加载镜像
docker commit 容器id 镜像名称:版本号
docker save -o 压缩文件名.tar 镜像名称:版本号
docker load -i 压缩文件
# 根据Dockerfile来构建镜像
docker build -f ./Dockerfile -t xxx:1.0 . # .代表寻址的路

创建容器

docker run -id --gpus all --name SY311 -v /home/qsun/桌面/SY:/root/SY sy311:4.0 /bin/bash

$$ \text{ docker run -id --gpus all --name SY311 -v \color{red}/home/qsun/桌面/SY\color{black}:\color{green}/root/SY \color{purple}sy311:4.0 \color{black}/bin/bash } \ \begin{cases} \color{red}外部主设备的项目文件夹路径(需要提前准备好) \ \color{green}容器内部的对应文件夹目录(会自动创建) \ \color{purple}镜像名与其对应版本 \end{cases} $$

当创建容器后, 红色文件夹(实际存在) 与 绿色文件夹(容器内存在) 会关联起来 -> 修改主机内实际存在的文件夹, 则容器内的该文件夹也会变

    scikit-learn==1.6.1 \
    spikingjelly==0.0.0.0.14 \
